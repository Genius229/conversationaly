GigaSTT 2.21.0 — тестовый Windows x64 runtime для CPU без AVX2

Это замена ТОЛЬКО движка GigaSTT в Conversationaly GigaSTT Dev 1.4.5,
не новый установщик приложения. Запись, настройка VAD, модели, история
и сохранённые аудиофайлы остаются без изменений.
Собственная диаризация GigaSTT в этот профиль не включена.

Состав: GigaSTT 2.21.0 + официальный Microsoft CPU ONNX Runtime 1.28.2.
Прежняя встроенная Pyke-библиотека с обязательным AVX2 не используется.
Обе onnxruntime DLL должны лежать рядом с gigastt.exe.
НЕ копируйте только EXE: нужна вся папка gigastt из архива.
В архиве нет Python, Intel SDE, моделей и записей пользователя.

ПРОВЕРКА БЕЗ ЗАМЕНЫ УСТАНОВЛЕННОЙ ВЕРСИИ
1. Распакуйте архив в новую папку.
2. Откройте PowerShell внутри распакованной папки gigastt.
3. Выполните: .\gigastt.exe --version
4. Выполните: .\gigastt.exe --help
5. Если справка не появилась или возникла ошибка, сразу выполните:
     "ExitCode: $LASTEXITCODE"
   Пришлите вывод. Установленную папку пока не заменяйте.

ПРОВЕРКА В CONVERSATIONALY
1. Полностью закройте приложение через меню значка в трее → Quit.
   Обычный крестик только скрывает окно.
2. Откройте папку: %LOCALAPPDATA%\Conversationaly GigaSTT Dev
3. Переименуйте существующую папку gigastt в gigastt-backup-1.4.5.
4. Скопируйте на её место целиком папку gigastt из этого архива.
5. Запустите приложение и повторите расшифровку уже импортированной записи.

Модели останутся здесь:
%APPDATA%\com.conversationaly.gigastt-dev\models\gigastt\2.18.0
Повторно скачивать модели или сбрасывать базу данных не требуется.

ОТКАТ
Закройте приложение через трей. Переместите тестовую папку gigastt за пределы
папки установки, затем верните gigastt-backup-1.4.5 имя gigastt.
Сохраняйте резервную копию до проверки и записи, и транскрибации.

ГРАНИЦЫ ПРОВЕРКИ
Точные результаты Windows-тестов и проверки инструкций Intel SDE Ivy Bridge
указаны на странице релиза. Они не заменяют проверку на реальном рабочем ПК.
Этот runtime не меняет требования к CPU у других встроенных движков
приложения — Whisper/GigaAM и моделей подготовки сводок.

ЗАЩИТНОЕ ПО
Блокировка микрофона и несовместимость CPU — отдельные проблемы. Замена
runtime не меняет правила Kaspersky. Необходимые точечные разрешения для
приложения согласуются с администратором рабочего ПК.
Если вручную задана переменная ORT_DYLIB_PATH, она может подменить библиотеку:
для проверки используйте процесс без такого переопределения.

runtime-inventory.json содержит версии, параметры сборки, происхождение
ONNX Runtime, хеши упакованных файлов и сведения об импортируемых DLL.
